# 평가 자료

전시가 끝난 뒤, 휴대폰으로 찍은 사진 18장(물건 15개)으로 인식과 매칭을 다시 재 본 자료다. 결과 요약은 [README](../../README.md#평가-결과)에 있다.

| 파일                                    | 내용                                                                                      |
| --------------------------------------- | ----------------------------------------------------------------------------------------- |
| `expected.csv`                          | 사진마다 새로 들어온 물건과, 정답·유사로 볼 종류와 색상. 인식을 돌리기 전에 적어 커밋했다 |
| `lost_reports.json`                     | 물건마다 주인이 적을 법한 분실 신고 15건. 역시 인식 전에 적었다                           |
| `recognized_1.csv` ~ `recognized_3.csv` | 같은 사진을 `findbox_photos.py`로 세 번 돌린 결과                                         |
| `score.py`                              | 위 자료를 채점한다                                                                        |

```bash
python docs/eval/score.py
```

- 사진은 개인 물건이라 올리지 않았다. 개인정보가 없는 세 쌍만 README의 예시로 `docs/images`에 있다. 결과 파일에서도 지역 이름은 ○○으로 가렸다.
- 첫 사진에는 이미 휴대폰이 놓여 있었다. 그래서 마지막에 찍은 빈 종이 사진을 복사해 맨 앞에 두고(`00_…`) 그것과 비교했다.
- 정답표와 분실 신고는 물건 주인이 아니라 AI가 사진만 보고 적었다.
